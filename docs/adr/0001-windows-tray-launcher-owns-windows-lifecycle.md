# Windows Tray Launcher owns Windows lifecycle

The Windows Tray Launcher is the Windows-specific supervisor for the Runtime Bundle, owning start, authoritative health, bounded restart, stop, hidden login autostart, single-instance tray UX, and only the process tree that it spawns. In Phase 1 it supervises `tunnel-client.exe` as the long-lived root; a Windows command-based MCP profile makes `tunnel-client` launch the `hands.exe` MCP child, so the launcher does not keep a second `hands.exe --http` daemon merely for configuration. Launcher-owned child roots are grouped under native Windows lifecycle ownership so exit/crash can terminate their descendants, while unrelated `hands.exe` or `tunnel-client.exe` processes are never discovered or killed by executable name. Runtime readiness requires both a live owned tunnel process and affirmative tunnel readiness rather than process existence alone. This keeps the Hands Runtime lean and ToolBridge-first while filling the Windows supervisor gap outside MCP dispatch.
